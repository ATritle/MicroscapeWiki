# Bazaar walkthrough screenshots

Captured from the official Microscape game UI on November 20, 2026.
Source: https://microscape.cc/play/ · artwork credits: https://microscape.cc/credits/

The images retain the actual game controls and values. Crops include only the
relevant game UI, excluding browser tabs, bookmarks, profile information and
personal order-history rows. The buy and sell forms are unsubmitted examples;
no order was placed to make these screenshots. Prices, quantities and clock
times are illustrative snapshots rather than live market quotations.

`docs/bazaar-walkthrough.js` supplies the captions, alt text and directions.
The posting and cancellation timelines are explicitly labeled illustrations.
